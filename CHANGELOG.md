## [1.0.0] - 2026-04-04

### Added
- Licensing policy updates
- Community section and Telegram links across documents
- Reviewers and builders section
- YouTube video for curriculum overview in Roadmap section
- Docs versioning guide and automation
- Tab switcher component for outcomes section
- JourneyMap and roadmap components
- Motivational message for learners in contributing guidelines
- Issue templates
- Pre-deploy checks
- Particle background and glassmorphism homepage design

### Changed
- Reorganized components and docs assets
- Refactored engineering fundamentals program and renamed to AI Engineering Roadmap
- Restructured landing page sections and enhanced styling
- Updated curriculum overview with structured pathway and mission statement
- Renamed modules for clarity and consistency across curriculum
- Updated sidebar labels and navigation
- Enhanced Academy Card with warm gold accents and featured badge
- Updated NLP track resources with new links
- Reorganized Softlanding core systems into modular files
- Rewrote README with tabular curriculum and best practices

### Fixed
- Telegram button styles and visibility
- Broken links across specialization and module pages
- Sidebar confusion for specialization tracks
- SQL resource link updated to intermediate HackerRank course
- Reviewers section formatting and GitHub link removal
- Oybek Eraliyev bio update
- Difficulty level for LLM resources
- Formatting and consistency in NLP and prerequisites sections
- Removed all "coming soon" rubrics from documentation
- URL generation inconsistencies for md files
- Small UI fixes in school program page
- Enhanced sidebar styling for improved visibility
- Favicon updated from SVG to ICO format

### Removed
- Local dev docs
- Docs versioning storage (CI)
- HorizontalStepper component (replaced by JourneyMap)
- Capstone links and time estimates from specialization tracks
- Redundant sections in prerequisites table
