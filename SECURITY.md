# Security Policy

## Supported Versions

We support the latest version of the curriculum and codebase.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of our community seriously. If you discover a security vulnerability in this project, please report it privately.

**Do not open a public issue.**

### How to Report

Please email `security@humblebee.ai` with a description of the vulnerability. We will acknowledge your email within 48 hours.

### Response Timeline

1. **Triage**: We will confirm the vulnerability and determine its impact.
2. **Fix**: We will work on a patch or mitigation.
3. **Disclosure**: Once fixed, we will release a security update and credit you (if desired).
