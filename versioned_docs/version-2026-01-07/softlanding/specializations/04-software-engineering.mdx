## <Target /> Goal

Build production-grade, scalable systems. Learn the architecture patterns, tools, and practices that distinguish hobby projects from enterprise software.

## <Wifi /> 1. Networking Fundamentals

### Core Concepts
<ResourceCard 
  type="course"
  title="Computer Networking Course"
  url="https://www.youtube.com/playlist?list=PLIhvC56v63IJVXv0GJcl9vO5Z6znCVb1P"
  duration="8-10 hours"
  difficulty="intermediate"
  why="Systematic walkthrough of OSI layers, protocols, and performance so you can reason about production traffic."
/>

Understand how data travels to debug and optimize effectively.

**Key Topics:**
- **OSI Model**: Layers 3-7 (Network to Application).
- **Protocols**: TCP/IP, DNS, HTTP/HTTPS.
- **Performance**: Load balancing, CDNs, SSL/TLS.

**Action Items:**
1. Watch videos on OSI model and HTTP.
2. Use `ping`, `traceroute`, and `curl` to trace requests.
3. Analyze a website's traffic using Browser DevTools.

**Action Items:**

3. Draft an architecture document for a new service.

  url="https://learn.mongodb.com/learning-paths/introduction-to-mongodb"
  duration="4-6 hours"
  difficulty="intermediate"

/>

<ResourceCard 
  type="docs"
  title="Alembic Tutorial"
  url="https://alembic.sqlalchemy.org/en/latest/tutorial.html"
  duration="2-3 hours"
  difficulty="intermediate"
  why="Shows how to manage schema migrations safely in production using Alembic."
/>

Design efficient schemas and manage data integrity.

**Key Topics:**
- **Design**: ERD, Normalization (1NF-3NF), Indexing.
- **SQL**: Joins, Transactions, ACID properties.
- **NoSQL**: Document model, Aggregation pipelines.
- **Migrations**: Version control for database schemas.

**Action Items:**
1. Create an ERD for an e-commerce system.
2. Implement the schema in PostgreSQL and write complex queries.
3. Set up Alembic for automated migrations.

  duration="1-2 hours"

## <Rocket /> Capstone Project

**Duration**: 4-6 weeks | **Mentor-Led**

Build a production-grade application combining all modules:
- Microservices architecture with REST APIs.
- SQL database, Docker containerization, and CI/CD.
- Mobile or Web frontend.

**Evaluation**: Code quality, Test coverage (>80%), Documentation, Deployment.
