# Systems, Networking & Data

**Status: Required.**

## R5. Systems, Networking, and Data Foundations {#r5}

Purpose: understand and debug the path from a request to an application and its data. Prerequisite: Engineering Fundamentals terminal and basic SQL; [R1](/draft/softlanding/core-systems/software-engineering#r1).

### Learn

- Switch/router intuition, IP addresses, public/private networks, CIDR, and ports.
- HTTP requests and responses, status codes, headers, HTTPS concepts, and DNS resolution.
- Linux processes, permissions, environment variables, logs, and SSH keys.
- Distinguish a stopped process, wrong listening address, wrong port, DNS issue, and blocked connection.
- Connect Python to a database using parameterized queries and a basic transaction.

### Practice

- Inspect your interface, address, route, listening ports, and a running application's process.
- Use an HTTP client such as curl to inspect successful and failing requests. Diagnose mentor-provided faults in an isolated lab.
- Connect to an assigned machine using SSH, or complete the equivalent local SSH lab.
- Persist application records in SQLite and verify the data after restarting the process.
- Adapt the roadmap's architecture-diagram exercise: show client, public entry point, application, and database; label allowed traffic and exposure.

### Expected output

A network/request-flow diagram, a short troubleshooting record, and a working database integration. You can explain each connection and distinguish local application failures from network failures.
