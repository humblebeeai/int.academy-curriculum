## APIs, Containers, and Deployment {#r6}

make your AI component usable as a service.

**Before you start:** [Software Engineering for AI](/draft/softlanding/core-systems/software-engineering#r1) and [Systems, Networking & Data](/draft/softlanding/core-systems/systems-networking-data#r5), plus a working inference function from [applied ML](/draft/softlanding/core-systems/applied-ml-deep-learning#r2), [deep learning](/draft/softlanding/core-systems/applied-ml-deep-learning#r3), or [LLM Applications](/draft/softlanding/core-systems/llm-applications#r4).

### Learn

- FastAPI routes, Pydantic request/response models, validation, error responses, and basic CORS.
- Load reusable model resources efficiently; use current FastAPI lifecycle guidance.
- Separate inference logic from HTTP handling; test both.
- Build a Docker image, configure runtime values, and run the service locally.
- Automate tests in a basic workflow, deploy to an assigned environment, and inspect health and logs.

### Practice

- Expose your model or LLM feature through a validated endpoint and provide example requests.
- Test a valid request, an invalid input, and an inference failure; add a basic health endpoint.
- Build and run a Docker image; verify configuration and logs from a fresh run.
- Add an automated test workflow and deploy the service. Use a small browser client or command-line client to demonstrate it.

### Expected output

A deployed service, a Dockerfile, passing tests, an automated test workflow, and setup/use instructions. Include model or LLM evaluation results separately from software test results. Deployment may use Academy infrastructure or an agreed hosted environment.
