# R2. Applied ML and Evaluation

Purpose: choose and assess models using evidence. Prerequisite: Engineering Fundamentals data manipulation, statistics, and linear algebra; begin [R1](/draft/softlanding/core-systems/r1-software-engineering) alongside this module.

## Learn

- Supervised regression and classification; linear/logistic models, trees, random forests, and SVM intuition.
- Preprocessing and a reproducible scikit-learn pipeline.
- Baselines, train/validation/test splits, cross-validation, and data leakage.
- Classification metrics: precision, recall, F1, confusion matrix, ROC-AUC, and precision–recall evaluation. Choose metrics based on the task.
- Regression metrics at an introductory level; overfitting, underfitting, and error analysis.

## Resources

- [IBM: What is machine learning?](https://www.ibm.com/think/topics/machine-learning) — Roadmap resource; introductory overview of learning, inference, and generalization.
- [StatQuest: Linear models, logistic regression, trees, and random forests](https://statquest.org/video_index.html) — Roadmap resource family; use the named topic videos in the official index. Focus on the main ideas and assumptions, then implement the models.
- [StatQuest: Support Vector Machines](https://www.youtube.com/playlist?list=PLblh5JKOoLUL3IJ4-yor0HzkqDQ3JmJkc) — Roadmap resource; study the decision-boundary and margin intuition. Detailed derivations are optional support.
- [Roadmap evaluation-metrics reference](https://www.analyticsvidhya.com/blog/2019/08/11-important-model-evaluation-error-metrics/) — Retained roadmap reading; use the classification section as a companion reference. Use official scikit-learn documentation for implementation.
- [scikit-learn: Getting Started](https://scikit-learn.org/stable/getting_started.html) — Added runnable examples for estimators, preprocessing, pipelines, and evaluation.
- [scikit-learn: Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) — Added required reference; study inconsistent preprocessing and data leakage.

## Practice

- Choose a small public dataset or a built-in scikit-learn dataset; define the target and a task-appropriate metric.
- Create a baseline and compare at least two candidate models using the same split and preprocessing rules.
- Inspect mistakes and explain a useful improvement. Keep final test data out of model and preprocessing selection.
- Run a small regression example if your main project is classification, or a classification example if your main project is regression.

## Expected output

A reproducible modeling notebook or script, a results comparison, and a short error-analysis note. You can justify the split, baseline, metric, and model choice, and identify a leakage risk.
