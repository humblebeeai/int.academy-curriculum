## Learn

- Distinguish a predefined workflow from an agent that chooses actions.
- Define tools with clear inputs, outputs, validation, and failure behavior.
- Manage context, intermediate state, step/time limits, and recovery.
- Use scoped permissions and explicit approval points for actions that need them.
- Understand MCP's role in connecting applications to tools and data.

## Practice

- Choose a bounded task, such as searching approved records and producing a validated report.
- Implement tools and a workflow or agent; log calls and enforce stopping limits.
- Test invalid arguments, unavailable tools, repeated actions, and incomplete tasks.
- Compare with a simple baseline and explain whether agentic control improves the result.

## Expected output

A working tool-based workflow, an evaluation set, execution traces, and a design explanation. An MCP implementation can deepen this elective; a framework certificate alone does not complete it.

## Workload

Workload estimate pending pilot. Include practice, debugging, review, and revision in your study time.

## Submission evidence and completion checks

Keep the expected output, runnable instructions, test/evaluation results where applicable, and your explanation of a meaningful failure. Submit through review and record the resulting revision. Explain your approach and diagnose a relevant failure during review. Revise incomplete evidence after feedback; resource completion alone does not establish competence.
