# Core Systems

Core Systems connects Engineering Fundamentals to specialization. Complete five required modules covering all six R1–R6 learning requirements, exactly two electives, and the integrated project.

## Prerequisites

Complete [Engineering Fundamentals](/draft/engineering-fundamentals) or demonstrate equivalent skills through the Academy direct-entry review. You should be able to write and debug Python, use a local environment and Git, manipulate data with NumPy/Pandas, query SQL, interpret plots, and use basic linear algebra, probability, and statistics. Derivatives preparation is provided within deep learning; no prior FastAPI, Docker, PyTorch, or LLM application experience is required.

## Required modules

| Required module | Guide requirements | Focus |
| --- | --- | --- |
| [Software Engineering for AI](/draft/softlanding/core-systems/software-engineering) | R1 | Project structure, tests, collaboration, verified AI-assisted work |
| [Applied ML & Deep Learning](/draft/softlanding/core-systems/applied-ml-deep-learning) | R2 and R3 | Evaluation, classical models, training, PyTorch, pretrained inference |
| [LLM Applications](/draft/softlanding/core-systems/llm-applications) | R4 | Structured outputs, context, evaluation, failure handling |
| [Systems, Networking & Data](/draft/softlanding/core-systems/systems-networking-data) | R5 | HTTP/DNS, Linux, SSH, troubleshooting, persistence |
| [APIs, Containers & Deployment](/draft/softlanding/core-systems/apis-containers-deployment) | R6 | FastAPI, Docker, automated tests, deployment |

## Learning sequence

Start Software Engineering for AI and keep using its habits throughout the stage. Complete Applied ML before deep learning, including the short derivatives preparation before R3. Systems can run alongside modeling work. Begin APIs and deployment after systems and a working inference function from ML, deep learning, or LLM applications.

Build the integrated project incrementally. Retain the separate R2 and R3 exercises even if the final project uses an LLM. Required exercises may share a repository with clear directories and run instructions.

## Electives {#electives}

The following are sibling modules within Core Systems. Complete exactly two after their prerequisites. An optional resource within a required module does not count as an elective.

| Elective module | Prerequisites |
| --- | --- |
| [Retrieval and RAG](/draft/softlanding/core-systems/e1-retrieval-rag) | Software Engineering, LLM Applications, and API basics |
| [Agents and Tool-Based Workflows](/draft/softlanding/core-systems/e2-agents-tools) | Software Engineering, LLM Applications, and API basics |
| [Model Adaptation and Experimentation](/draft/softlanding/core-systems/e3-model-adaptation) | Applied ML & Deep Learning; LLM Applications for LLM projects |
| [Backend Architecture and Data Systems](/draft/softlanding/core-systems/e4-backend-data) | Software Engineering, Systems & Data, APIs, and SQL |
| [Delivery, Monitoring, and MLOps](/draft/softlanding/core-systems/e5-delivery-mlops) | Software Engineering, Systems & Data, APIs, and AI evaluation |

Choose based on a capability and a project where you can practice it. Examples: Retrieval + Agents for grounded workflows; Model Adaptation + MLOps for experimentation and delivery; Backend + MLOps for reliability. Other combinations are valid when supported by your project.

Electives introduce capabilities explored more deeply in specialization. Keep each to one defined feature, an evaluation approach, and an explanation of tradeoffs. Both electives may extend one project, but document their outcomes and evidence separately.

## Project and completion

Deliver the [Integrated Project & Handover](/draft/softlanding/core-systems/handover), revise it after review, and meet the completion checks. Watching tutorials alone does not establish the outcomes. Continue into [specialization](/draft/softlanding/specializations) afterward.

## Workload

Use the provisional estimates where supplied. Other workloads remain pending pilot. Include implementation, debugging, review, and revision.
