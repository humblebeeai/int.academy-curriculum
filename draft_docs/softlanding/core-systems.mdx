# Core Systems Overview

Build the shared skills to turn AI ideas into tested, working applications. Complete all six required modules, choose two of five electives, and bring your learning together in one integrated project.

## Purpose

Core Systems connects Engineering Fundamentals to specialization. You will learn how models behave, how software is organized, how services communicate, and how to deliver an application that another person can run and inspect.

## Goals

- Develop sound judgment about model selection, evaluation, and failure analysis.
- Write maintainable Python projects and use AI development tools with deliberate review and verification.
- Build with classical ML, a small neural network, and pretrained models or LLMs.
- Understand the systems that connect a model to users: HTTP, networks, processes, databases, APIs, and containers.
- Practice testing, deployment, troubleshooting, documentation, and revision after feedback.

## Expected outcomes

By the end, you can explain your model or LLM choice, evaluate its behavior, implement a service around it, test the important paths, deploy it, and diagnose common failures. Your repository will show both working results and the reasoning behind your decisions.

## Prerequisites

Enter after completing Engineering Fundamentals or demonstrating equivalent skills through the Academy's direct-entry process. Before starting, you should be able to:

- Write and debug Python functions, work with common data structures, and handle files.
- Use the terminal, manage an environment, and collaborate with Git.
- Manipulate data with NumPy and pandas; write basic SQL and inspect data with plots.
- Use basic linear algebra, probability, and statistics to follow model explanations. Complete the derivatives bridge before R3.
- Review gaps before taking a dependent module. You do not need prior FastAPI, Docker, PyTorch, or LLM application experience.

## How the stage works

- Required: complete R1–R6, including their practice tasks and expected outputs.
- Electives: complete exactly two of E1–E5. Choose based on your interests and intended specialization.
- Integrated project: deliver one usable AI service, then revise it after review.
- Resources support the work. Watching a video or finishing a tutorial alone does not demonstrate the module's outcomes.

## Using the resources

Each module specifies what to study and what to build. Follow the assigned sections; complete additional material when it helps your project. Tutorials are starting points: change the dataset, inputs, behavior, or tests so your submission demonstrates your own understanding.

The guide preserves the roadmap's resources for overlapping topics and adds documentation and runnable tutorials for the expanded scope. Some resources are labelled optional support; they do not count as an elective.

The six-module organization below replaces the earlier four-module roadmap.

Everyone completes all six modules. Begin R1 first and continue using its engineering habits throughout the stage.

- [R1. Software Engineering for AI — project structure, tests, collaboration, and AI-assisted development.](/draft/softlanding/core-systems/r1-software-engineering)
- [R2. Applied ML and Evaluation — models, baselines, correct splits, metrics, and error analysis.](/draft/softlanding/core-systems/r2-applied-ml)
- [R3. Deep Learning and Pretrained Models — a small training loop, debugging, and pretrained inference.](/draft/softlanding/core-systems/r3-deep-learning)
- [R4. LLM Application Fundamentals — validated outputs, context, evaluation, latency, and cost.](/draft/softlanding/core-systems/r4-llm-applications)

## Suggested progression

Work through R1 and R2, then R3 and R4. R5 can run alongside the modeling work. Start R6 once you have a working inference function and enough networking knowledge to understand requests and connections.

Build the integrated project incrementally as you learn. Required exercises can live in the same repository, with clear directories and run instructions.

## What carries forward from the roadmap

- ML Fundamentals: IBM's introduction, StatQuest, Andrew Ng, and the evaluation-metrics reference.
- Intro to AI Engineering: CS231n lectures 2–4, UvA Tutorial 2, Karpathy's videos, and selected Clean Code topics. LeetCode remains optional consolidation.
- Systems & Networking: NetworkChuck's introductory lessons, IP addressing, network diagnostics, and the architecture-diagram exercise.
- Infra Basics: API and FastAPI videos, Docker 101, SSH concepts, and optional HTML/DOM starters.

## What is added

Applied model-evaluation exercises, project/dependency management, automated tests, verified AI-assisted changes, LLM structured outputs and evaluation, explicit HTTP/DNS lessons, database integration, and a basic automated test workflow.
