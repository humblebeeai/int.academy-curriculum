# NumPy

## Purpose and prerequisites

Basic Python and environment setup.

## Required Topics

- Creating and inspecting arrays
- Shapes, dimensions, sizes, and data types
- Indexing and slicing
- Boolean masks
- Reshaping and transposing
- Broadcasting
- Vectorized operations
- Aggregations and the axis parameter

## Learning and Practice

- Complete [NumPy: The Absolute Basics for Beginners](https://numpy.org/doc/stable/user/absolute_beginners.html).
- Complete [CodeSignal: NumPy Basics](https://codesignal.com/learn/courses/numpy-basics), including its practice exercises.

## Completion Requirement

The learner can filter, reshape, transform, and summarize multidimensional data using NumPy without unnecessary Python loops.
