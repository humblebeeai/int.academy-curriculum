# Algorithms and Problem Solving

**Status: Optional.** Complete its prerequisites before starting. Engineering Fundamentals does not require a minimum number of optional modules.

## Purpose and prerequisites

Go beyond the required kit by choosing algorithms deliberately and comparing alternatives.

Prerequisites: The required HackerRank preparation kit and debugging practice.

Review [Required algorithms](/draft/engineering-fundamentals/terminal-algorithmic-basics#algorithms) and [debugging](/draft/engineering-fundamentals/terminal-algorithmic-basics#debugging) before starting.
