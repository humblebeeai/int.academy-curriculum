# Algorithms and Problem Solving

## Purpose and prerequisites

Develop reasoning about data structures, algorithm choices, and edge cases. Basic Python and debugging skills are required.

## Required learning and resources

## Week 1 — Basic Problem-Solving Patterns

- Array traversal and aggregation
- String parsing and transformation
- Dictionaries, sets, and frequency counting
- Two-dimensional arrays and matrix traversal
- Counting sort
- Greedy sorting
- Fixed-size sliding windows
- Bitwise operations and XOR
- [Week 1 challenges](https://www.hackerrank.com/interview/preparation-kits/one-month-preparation-kit/one-month-week-one/challenges)

## Week 2 — Algorithmic Reasoning

- Frequency-based problems
- Sorting and sequence manipulation
- Greedy range minimization
- Nested and dynamic arrays
- Query processing and simulation
- Grid manipulation
- Prefix sums and equilibrium points
- Recursion
- Basic mathematics and game strategy
- Prime-number reasoning
- Bitwise problem-solving
- [Week 2 challenges](https://www.hackerrank.com/interview/preparation-kits/one-month-preparation-kit/one-month-week-two/challenges)

## Week 3 — Core Data Structures

- Grid simulation and repeating-state detection
- Arrays, permutations, and inversion counting
- Frequency validation
- Searching sorted data
- Binary search and ordered traversal
- Singly linked lists
- Doubly linked lists
- Inserting, reversing, and merging linked lists
- Hash-map lookup
- Stacks
- Queues
- Implementing a queue using two stacks
- Bracket matching
- Command history and undo operations
- [Week 3 challenges](https://www.hackerrank.com/interview/preparation-kits/one-month-preparation-kit/one-month-week-three/challenges)

## Week 4 — Intermediate and Advanced Algorithms

- Stack-based optimization
- Maximum subarrays
- Dynamic programming
- Combinatorial counting
- Modular arithmetic
- Heaps and priority queues
- Greedy coverage
- Sliding-window maximum queries
- Deques
- Difference arrays and prefix sums
- Greedy palindrome construction
- Minimum swaps and permutation cycles
- Tree traversal
- Binary search trees
- Lowest common ancestors
- Huffman trees and decoding
- Tries and prefix validation
- Breadth-first search
- Grid graphs
- Connected components and graph traversal
- [Week 4 challenges](https://www.hackerrank.com/interview/preparation-kits/one-month-preparation-kit/one-month-week-four/challenges)
