# Probability and Statistics

## Purpose and prerequisites

Interpret uncertainty and statistical evidence. Foundational algebra is required; calculus is not required.

Use [Khan Academy Statistics and Probability](https://www.khanacademy.org/math/statistics-probability). Follow the unit topics below if the provider changes navigation or numbering.

## Core Statistics

Status: Required — Prerequisite: Foundational algebra — Learning source: Khan Academy Statistics and Probability

Every Engineering Fundamentals learner must complete the following units:

### Unit 1 — Analyzing Categorical Data

Required competencies:

- Interpret frequency tables
- Interpret relative-frequency tables
- Work with two-way tables
- Compare categorical distributions
- Identify associations between categorical variables

### Unit 2 — Displaying and Comparing Quantitative Data

Required competencies:

- Read and create dot plots
- Read and create histograms
- Interpret box plots
- Compare distributions
- Describe center, spread, shape, and unusual values
- Select an appropriate data display

### Unit 3 — Summarizing Quantitative Data

Required competencies:

- Calculate and interpret mean and median
- Understand quartiles and interquartile range
- Calculate and interpret variance and standard deviation
- Understand the effect of outliers
- Select appropriate measures of center and spread

### Unit 4 — Modeling Data Distributions

Required competencies:

- Understand density curves
- Standardize values using z-scores
- Interpret percentiles
- Work with normal distributions
- Apply the empirical rule
- Compare observations from different distributions

### Unit 5 — Exploring Bivariate Numerical Data

Required competencies:

- Read scatterplots
- Identify direction, form, and strength
- Understand correlation
- Distinguish correlation from causation
- Use and interpret trend lines
- Interpret residuals
- Identify unusual observations

### Unit 6 — Study Design

Status: Excluded

This unit is not required for Engineering Fundamentals.

Learners do not need to complete:

- Statistical-question lessons
- Sampling methods
- Surveys
- Observational-study design
- Experimental design
- Study-design quizzes
- The Unit 6 test

### Unit 7 — Probability

Required competencies:

- Understand sample spaces and events
- Calculate basic probabilities
- Use addition and multiplication rules
- Work with compound events
- Understand conditional probability
- Recognize independent and dependent events
- Use simulations to estimate probability

### Unit 8 — Counting, Permutations, and Combinations

Required competencies:

- Apply the fundamental counting principle
- Distinguish permutations from combinations
- Calculate permutations
- Calculate combinations
- Use counting techniques in probability problems

### Unit 9 — Random Variables

Required competencies:

- Understand discrete and continuous random variables
- Create and interpret probability distributions
- Calculate expected value
- Calculate and interpret variance and standard deviation
- Transform and combine random variables
- Understand binomial random variables
- Understand geometric random variables

### Unit 10 — Sampling Distributions

Required competencies:

- Distinguish populations, samples, parameters, and statistics
- Understand sampling variability
- Interpret sampling distributions
- Work with sample proportions
- Work with sample means
- Understand standard error
- Apply normal approximations where appropriate
- Understand the Central Limit Theorem conceptually
The excluded Unit 6 material should not be directly assessed here.

### Unit 11 — Confidence Intervals

Required competencies:

- Understand point estimates and intervals
- Interpret confidence levels
- Understand margin of error
- Construct and interpret confidence intervals
- Check the mathematical conditions for an interval
- Understand how sample size affects precision
- Avoid common confidence-interval interpretation errors

### Unit 12 — Significance Tests

Required competencies:

- State null and alternative hypotheses
- Understand test statistics
- Interpret p-values
- Select a significance level
- Make evidence-based conclusions
- Understand Type I and Type II errors
- Recognize statistical versus practical significance
- Perform the one-sample tests included in the Khan Academy unit

## Core Completion Requirements

To pass the required Statistics component, learners must:

- Complete Units 1–5 and 7–12.
- Pass every required Khan Academy unit test with a score of at least 80%.
- Demonstrate the ability to interpret results, not only perform calculations.
- Pass an Academy verification assessment covering only the required units.
- The Khan Academy full-course challenge should not be used as the mandatory final assessment because it may include excluded Unit 6 and extension Units 13–16.

## Submission evidence

Submit required unit-test results and an interpretation exercise covering sampling distributions, confidence intervals, and a one-sample significance test. The Academy verification covers only required units. Revise gaps identified during review.

## Optional extension

[Advanced Statistical Inference](/draft/engineering-fundamentals/advanced-statistical-inference) contains Units 13–16 and earns one extension credit only when all four are completed.
