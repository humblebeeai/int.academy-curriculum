# Bash Scripting and Automation

[← Engineering Fundamentals modules](/draft/engineering-fundamentals)

**Elective module.** Choose this module if you want to develop this skill further. Complete the prerequisites first; Complete exactly two Engineering Fundamentals electives.

## Before you start

Turn repeated terminal commands into scripts using variables, arguments, conditions, loops, pipes, and redirection.

Prerequisites: Terminal commands and a working Python environment.

Review [Terminal](/draft/engineering-fundamentals/terminal-algorithmic-basics#terminal) and [environment setup](/draft/engineering-fundamentals/terminal-algorithmic-basics#environment-setup) before starting.
