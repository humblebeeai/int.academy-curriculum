# Data Foundations

## Purpose and prerequisites

Prepare data, query it, and communicate supported findings. Basic Python and a working environment are required. Use core descriptive statistics for exploratory analysis.

## Required modules

1. [NumPy](/draft/engineering-fundamentals/numpy): complete introductory array topics before linear algebra.
2. [Pandas and data cleaning](/draft/engineering-fundamentals/pandas-cleaning)
3. [SQL](/draft/engineering-fundamentals/sql)
4. [Exploratory analysis and visualization](/draft/engineering-fundamentals/exploratory-analysis)

Carry the cleaned Pandas dataset into exploratory analysis. Explain cleaning decisions and analysis limitations.
