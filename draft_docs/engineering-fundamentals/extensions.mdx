# Optional Extensions

These five extensions are optional. Complete the stated practical outcome for any extension you choose. Advanced Statistical Inference is a separate optional extension and also counts as one extension when completed in full.

## 1. Data Visualization with Seaborn and Plotly

Build clear visual explanations and interactive charts.

Practice resources:

- [Intermediate Data Visualization with Seaborn — DataCamp](https://www.datacamp.com/courses/intermediate-data-visualization-with-seaborn)
- [Introduction to Data Visualization with Plotly — DataCamp](https://www.datacamp.com/courses/introduction-to-data-visualization-with-plotly-in-python)

Expected outcome: Create static and interactive visualisations of a cleaned dataset and explain your chart choices.

## 2. GitHub Actions and Continuous Integration

Automate testing and learn to investigate failed workflow runs.

Practice resources — complete in order:

- [Hello GitHub Actions — GitHub Skills](https://github.com/skills/hello-github-actions)
- [Test with Actions — GitHub Skills](https://github.com/skills/test-with-actions)

Expected outcome: Configure automated tests for a Python repository and demonstrate a failed check followed by a successful fix.

## 3. Advanced SQL

Develop stronger analytical queries and explore query efficiency.

Practice resource:

- [Advanced SQL — Kaggle Learn](https://www.kaggle.com/learn/advanced-sql)

Expected outcome: Use analytic functions to answer questions across related rows and explain choices that improve query efficiency.

## 4. Bash Scripting and Automation

Turn repeated terminal commands into reusable scripts. Practise variables, arguments, conditions, loops, pipes, and output redirection.

Practice resources:

- [LearnShell — Interactive Shell Tutorial](https://www.learnshell.org/)
- [Software Carpentry: Pipes and Filters](https://swcarpentry.github.io/shell-novice/04-pipefilter.html)
- [Software Carpentry: Loops](https://swcarpentry.github.io/shell-novice/05-loop.html)
- [Software Carpentry: Shell Scripts](https://swcarpentry.github.io/shell-novice/06-script.html)

Expected outcome: Create a script that accepts input arguments, processes multiple files, and runs an existing Python program with clear usage instructions.

## 5. Algorithms and Problem Solving

Develop the ability to choose, implement, and explain algorithms.

Main reference:

- [Grokking Algorithms, Second Edition — Aditya Y. Bhargava](https://www.manning.com/books/grokking-algorithms-second-edition)

Additional practice:

- [HackerRank Algorithms](https://www.hackerrank.com/domains/algorithms) — select problems beyond the required preparation kit.

Expected outcome: Explain why a solution works, analyse its time and space complexity, and compare alternative approaches.

Resource access: DataCamp’s first chapters are free; full courses require a subscription. Grokking Algorithms is a paid book.
