## Before you start {#prerequisites}

You need basic Python, foundational algebra, and enough English to follow technical instructions. You do not need calculus or prior experience with data libraries.

<details>
<summary>Check your entry skills</summary>


#### Basic Python Programming

Before starting the stage, learners should be able to:

- Use variables, common data types and basic operators.
- Write conditional statements and loops.
- Define functions with parameters and return values.
- Work with lists, dictionaries, sets and strings.
- Import and use a Python module.
- Run, modify and explain a short Python program.

Advanced algorithms, object-oriented design and experience with data libraries are not entry requirements.

#### Foundational Mathematics

Learners should be comfortable with:

- Arithmetic, fractions, decimals and percentages.
- Ratios, powers and square roots.
- Variables and algebraic expressions.
- Rearranging and solving simple linear equations.
- Reading coordinates and simple graphs.

Calculus is not required. Linear algebra, probability and statistics are developed during the stage.

#### English Reading

You should be able to follow written instructions, understand programming problem statements and use introductory documentation in English. You may use a dictionary to clarify unfamiliar vocabulary.

#### Readiness Verification

A short Python exercise and foundational mathematics check should confirm readiness. Learners should explain their approach and adapt a solution when given a small change.

Identified gaps should be addressed through preparatory practice before beginning the modules that depend on those skills.

#### Preparation Within the Stage

Before beginning the linear algebra notebooks, learners must complete introductory NumPy topics covering array creation, shapes, dimensions, indexing and basic array operations.

This preparation is part of Engineering Fundamentals. Terminal skills, Git, debugging, Pandas, SQL and the remaining NumPy topics are also taught within the stage.

## Finish this stage {#completion}

Complete all three required modules and two electives. Keep your code, notebooks, explanations, and assessment results ready for review. Demonstrate the skills on each module page and revise any gaps after feedback.

Statistics requires at least 80% on every assigned unit test and a separate Academy verification. Other modules use their stated practical requirements; there is no overall percentage score.
