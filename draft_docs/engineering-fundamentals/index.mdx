# Engineering Fundamentals

## Purpose

Engineering Fundamentals establishes the shared technical foundation learners need before entering Soft Landing. It develops programming and problem-solving skills, practical mathematical understanding, and the ability to work with data using basic engineering workflows.

## Goals

The stage aims to:

- Strengthen Python programming and computational thinking.
- Develop systematic debugging and collaborative development habits.
- Connect linear algebra, probability and statistics to practical computations.
- Build competence in preparing, querying, analyzing and visualizing data.
- Help learners explain their work, verify results and continue learning independently.

## Expected Outcomes

By completing the required curriculum, learners should be able to:

- Programming and problem solving: Use Python to solve problems involving common data structures and algorithmic approaches. Explain their reasoning, consider edge cases and verify their solutions.

- Developer workflows: Navigate the filesystem using basic terminal commands. Use Git and GitHub to record changes, work on branches, open pull requests and resolve basic merge conflicts.

- Debugging: Reproduce a failure, interpret a traceback, inspect program state and fix ordinary runtime, logic and edge-case errors.

- Linear algebra: Use NumPy to work with vectors, matrices and tensor shapes. Perform and interpret basic operations, understand least squares, and explain the purpose of eigenvectors, SVD and PCA.

- Probability and statistics: Summarize and compare data, apply probability rules, work with random variables, and interpret sampling distributions, confidence intervals and one-sample significance tests.

- Data preparation: Use NumPy and Pandas to inspect, transform, clean and combine datasets. Explain important cleaning decisions and check the consistency of results.
- SQL: Answer analytical questions using filtering, aggregation, joins, subqueries, common table expressions, conditional logic and basic window functions.

- Analysis and communication: Create appropriate charts, communicate evidence-supported findings and describe limitations. Present understandable code, notebooks and explanations that others can review.

Extension outcomes are specified separately from the required core curriculum.

## Prerequisites

### Basic Python Programming

Before starting the stage, learners should be able to:

- Use variables, common data types and basic operators.
- Write conditional statements and loops.
- Define functions with parameters and return values.
- Work with lists, dictionaries, sets and strings.
- Import and use a Python module.
- Run, modify and explain a short Python program.

Advanced algorithms, object-oriented design and experience with data libraries are not entry requirements.

### Foundational Mathematics

Learners should be comfortable with:

- Arithmetic, fractions, decimals and percentages.
- Ratios, powers and square roots.
- Variables and algebraic expressions.
- Rearranging and solving simple linear equations.
- Reading coordinates and simple graphs.

Calculus is not required. Linear algebra, probability and statistics are developed during the stage.

### English Reading

Learners should be able to follow written instructions, understand programming problem statements and use introductory documentation in English. They may use a dictionary to clarify unfamiliar vocabulary.

### Readiness Verification

A short Python exercise and foundational mathematics check should confirm readiness. Learners should explain their approach and adapt a solution when given a small change.

Identified gaps should be addressed through preparatory practice before beginning the modules that depend on those skills.

### Preparation Within the Stage

Before beginning the linear algebra notebooks, learners must complete introductory NumPy topics covering array creation, shapes, dimensions, indexing and basic array operations.

This preparation is part of Engineering Fundamentals. Terminal skills, Git, debugging, Pandas, SQL and the remaining NumPy topics are also taught within the stage.

## Learning sequence

1. Confirm Python, mathematics, and English reading readiness.
2. Complete terminal, environment setup, Git, and debugging through [developer workflows](/draft/engineering-fundamentals/terminal-algorithmic-basics).
3. Complete introductory [NumPy](/draft/engineering-fundamentals/data-manipulation#numpy) before linear algebra notebooks.
4. Work through [linear algebra](/draft/engineering-fundamentals/linear-algebra) and [statistics](/draft/engineering-fundamentals/probability-statistics). Algorithm practice can run alongside these modules.
5. Complete Pandas, SQL, and exploratory analysis through [data foundations](/draft/engineering-fundamentals/data-manipulation).
6. Review all required evidence before entering [Core Systems](/draft/softlanding/core-systems).

## Completion

Complete every required module and its verification tasks. Keep code, notebooks, explanations, and assessment records available for review. Statistics has its own minimum unit-test scores. For other modules, demonstrate every stated competency rather than meeting an invented overall percentage.

[Extensions](/draft/engineering-fundamentals#optional-modules) are optional. No extension count is required for stage completion. Advanced Statistical Inference is one additional optional extension.
