# Debugging Fundamentals

Status: Required. Source estimate: 2–3 hours, provisional until piloted.

## Goal

Systematically locate, understand, and fix ordinary Python errors.

## Learning resources

Use selected sections from:

- [LabEx — Code Debugging Techniques](https://labex.io/tutorials/code-debugging-techniques-132737): tracebacks, print debugging, and the exercise
- [VS Code Python debugging tutorial](https://code.visualstudio.com/docs/python/python-tutorial#_configure-and-run-the-debugger): breakpoints, stepping, and inspecting variables

## Required topics

- Syntax errors
- Runtime errors
- Logic errors
- Reading Python tracebacks
- Reproducing a failure
- Isolating the failing code
- Inspecting values with print
- Setting basic IDE breakpoints
- Stepping through code
- Inspecting variables
- Verifying fixes with normal and edge-case inputs

## Assessment

The learner receives a small Python program containing:

- One runtime error
- One logic error
- One edge-case failure
- The learner must reproduce, explain, and fix all three problems.
- Logging, command-line debuggers, advanced breakpoints, and production observability are not required.

## Prerequisites

Basic Python and a working local environment.

## Submission evidence and completion checks

Submit the broken example, corrected code, and a note explaining each of the three failures and the inputs used to verify the fixes. The source estimate is 2–3 hours, provisional until piloted. Explain your approach and diagnose a relevant failure during review. Revise incomplete evidence after feedback; resource completion alone does not establish competence.
