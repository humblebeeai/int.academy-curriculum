# Terminal and Filesystem

## Purpose and prerequisites

Navigate and manipulate a local filesystem. No terminal experience is required.

## Required learning and resources

Complete all 19 lessons in [Linux Journey: Command Line](https://labex.io/linuxjourney/courses/command-line):

- The Shell
- pwd
- cd
- ls
- touch
- file
- cat
- less
- history
- cp
- mv
- mkdir
- rm
- find
- help
- man
- whatis
- alias
- exit

Completion requires doing the interactive exercises, not only reading the lessons.

We won’t add permissions, grep, pipelines, process management, or other Linux topics to this unit unless another module specifically requires them. Estimated time: 3–4 hours.

## Submission evidence and completion checks

Demonstrate navigation, file inspection, copying, moving, searching, and safe removal using a practice directory. Keep a short command transcript. The source estimate is 3–4 hours, provisional until piloted. Explain your approach and diagnose a relevant failure during review. Revise incomplete evidence after feedback; resource completion alone does not establish competence.
