# Linear Algebra Foundations

## Purpose and prerequisites

Connect mathematical operations to practical AI computations. Complete foundational algebra and introductory NumPy array creation, shapes, dimensions, indexing, and operations first.

## Main resource

[Jon Krohn — Linear Algebra for Machine Learning](https://www.jonkrohn.com/posts/2021/5/9/linear-algebra-for-machine-learning-complete-math-course-on-youtube)

The accompanying [Python notebooks](https://github.com/jonkrohn/ML-foundations) are required.

## Unit 1: Vectors and tensors

- Scalars, vectors, matrices, and tensors
- Tensor dimensions and shapes
- Vector addition and scaling
- Norms and unit vectors
- Dot product
- Distance and cosine similarity

Learners should be able to represent and manipulate these objects using NumPy.

## Unit 2: Matrices and transformations

- Matrix operations
- Matrix multiplication
- Transpose
- Identity, diagonal, and symmetric matrices
- Matrices as transformations
- Shape compatibility

Learners should be able to predict matrix multiplication output shapes and explain what a matrix transformation does.

## Unit 3: Linear systems and approximation

- Systems of linear equations
- `Ax = b`
- Matrix inverse
- Rank and linear independence
- Exact versus approximate solutions
- Pseudoinverse
- Least-squares regression

Learners should understand when a system can be solved and why least squares is used when an exact solution is unavailable.

## Unit 4: Eigenvectors, SVD, and PCA

- Eigenvectors and eigenvalues
- Eigendecomposition
- Singular value decomposition
- Low-rank approximation
- Principal component analysis

Learners should understand these concepts visually and apply them using NumPy. Long manual calculations are not required.

## Unit 5: Linear algebra in AI

- Dataset shapes: samples and features
- Neural-network weight matrices
- Batch dimensions
- Embedding vectors and similarity
- Basic attention matrix shapes
- Broadcasting and dimension errors

Learners should be able to follow tensor shapes through a small AI computation and diagnose common shape mistakes.

## Required practice

- Short exercises from the Jon Krohn course
- Four small Python notebooks
- Tensor-shape and debugging questions
- Small hand calculations using two- or three-dimensional examples
- There is no integrated project.

## Passing requirements

Learners must demonstrate that they can:

- Work with vectors, matrices, and tensor shapes
- Perform and interpret dot products and matrix multiplication
- Understand linear systems, rank, and least squares
- Explain the purpose of eigenvectors, SVD, and PCA
- Implement the main operations with NumPy
- Track tensor shapes in basic AI examples

## Not required

- Formal proofs
- Abstract vector-space theory
- Change-of-basis calculations
- Gram–Schmidt calculations
- Detailed row, column, and null-space theory
- Large determinants or inverses by hand
- Deriving eigendecomposition or SVD algorithms
