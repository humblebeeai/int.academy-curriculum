# Git and GitHub

Status: Required. Source estimate: 5–6 hours, provisional until piloted.

## Goal

Use Git and GitHub to track changes and contribute through a basic collaborative workflow.

## Learning resources

Complete these free courses from [GitHub Skills](https://skills.github.com/):

- [Introduction to Git](https://github.com/skills/introduction-to-git)
- [Introduction to GitHub](https://github.com/skills/introduction-to-github)
- [Resolve Merge Conflicts](https://github.com/skills/resolve-merge-conflicts)
- Complete the beginner sections of [Learn Git Branching](https://learngitbranching.js.org/) covering commits, branches, merging, and remotes.

## Required topics

- Repositories
- Working tree and staging area
- git status
- git diff
- git add
- git commit
- Meaningful commit messages
- git log
- Creating and switching branches
- Merging
- Basic conflict resolution
- Cloning repositories
- Remote repositories
- Fetching, pulling, and pushing
- .gitignore
- Pull requests
- Basic code review

## Assessment

The learner must:

- Clone a repository.
- Create a feature branch.
- Make and inspect changes.
- Create meaningful commits.
- Push the branch to GitHub.
- Open a pull request.
- Resolve an intentionally created merge conflict.
- Complete the merge.
- Advanced rebasing, cherry-picking, Git internals, GitHub Actions, and release management are not required.

## Prerequisites

Complete terminal basics and environment setup.

## Submission evidence and completion checks

Submit a repository and reviewed pull request showing the branch, meaningful commits, and resolved merge conflict. The source estimate is 5–6 hours, provisional until piloted. Explain your approach and diagnose a relevant failure during review. Revise incomplete evidence after feedback; resource completion alone does not establish competence.
