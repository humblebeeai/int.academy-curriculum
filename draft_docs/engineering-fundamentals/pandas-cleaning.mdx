# Pandas and Data Cleaning

## Purpose and prerequisites

Basic Python, environment setup, and introductory NumPy.

## Required Topics

- Series and DataFrames
- Loading and exporting tabular data
- Inspecting rows, columns, and data types
- Selecting, filtering, and sorting
- Grouping and aggregation
- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent categories
- Creating and transforming columns
- Merging and concatenating datasets

## Learning and Practice

- Complete [Kaggle Learn: Pandas](https://www.kaggle.com/learn/pandas), including all exercises.
- Complete [Kaggle Learn: Data Cleaning](https://www.kaggle.com/learn/data-cleaning), including all exercises.

## Completion Requirement

The learner can identify data-quality problems, produce an analysis-ready dataset, and explain every important cleaning decision.
