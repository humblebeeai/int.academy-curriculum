# SQL

## Purpose and prerequisites

Basic data-handling concepts; no database experience is required.

## Required Topics

- Relational tables and keys
- SELECT, aliases, and calculated columns
- WHERE and ORDER BY
- Aggregate functions
- GROUP BY and HAVING
- Inner and outer joins
- Subqueries
- Common table expressions
- CASE
- NULL handling
- Basic window functions
- Indexing intuition

## Learning and Practice

- Work through [SQLTutorial.org](https://www.sqltutorial.org/), including its examples and quizzes.
- Practise with the Basic and Intermediate challenges in [HackerRank SQL](https://www.hackerrank.com/domains/sql).

## Completion Requirement

The learner can answer analytical questions involving filtering, aggregation, joins, CTEs, conditional logic, and window functions.
