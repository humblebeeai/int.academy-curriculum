# Additional Resources to Learn

A curated list of high-quality resources to supplement the HumbleBeeAI Academy curriculum.

## Deep Learning & Machine Learning

- **[Hugging Face Learn <ExternalLink size={12} />](https://huggingface.co/learn)**: Excellent practical tutorials on Transformers, Diffusion models, and Deep RL.
- **[Fast.ai <ExternalLink size={12} />](https://www.fast.ai/)**: Top-down approach to Deep Learning.
  - [Fastbook Chapter 1 <ExternalLink size={12} />](https://github.com/fastai/fastbook/blob/master/01_intro.ipynb): Intro to Deep Learning.
- **[Andrej Karpathy's YouTube Channel <ExternalLink size={12} />](https://www.youtube.com/@AndrejKarpathy)**: "Neural Networks: Zero to Hero" series. The gold standard for understanding LLMs and Backprop from scratch.
- **[Papers with Code <ExternalLink size={12} />](https://paperswithcode.com/)**: Browse the state-of-the-art in ML papers linked to their official code implementations.

## Python & Software Engineering

- **[Real Python <ExternalLink size={12} />](https://realpython.com/)**: High-quality articles and tutorials on Python best practices.
- **[Full Stack Python <ExternalLink size={12} />](https://www.fullstackpython.com/)**: Guide to every part of the Python web application stack.
- **[Command Line Crash Course <ExternalLink size={12} />](https://learnpythonthehardway.org/book/appendixa.html)**: Practical command-line fundamentals, shell navigation, and core terminal habits.
- **[System Design Primer <ExternalLink size={12} />](https://github.com/donnemartin/system-design-primer)**: Comprehensive guide for key systems design interviews and concepts.

## Mathematics

- **[3Blue1Brown Essence of Linear Algebra <ExternalLink size={12} />](https://www.3blue1brown.com/topics/linear-algebra)**: Visual intuition for vectors, matrices, and transformations.
- **[StatQuest with Josh Starmer <ExternalLink size={12} />](https://www.youtube.com/c/joshstarmer)**: Statistics and ML algorithms explained simply and clearly.
- **[Immersive Linear Algebra <ExternalLink size={12} />](http://immersivemath.com/ila/index.html)**: Interactive linear algebra textbook.

## Specialized Tracks

- **Computer Vision**: [PyTorch Image Models (timm) <ExternalLink size={12} />](https://github.com/rwightman/pytorch-image-models) - Library of SOTA image classification models.
- **NLP**: [LangChain Documentation <ExternalLink size={12} />](https://python.langchain.com/en/latest/) - Learn to build applications with LLMs.
- **Data Science**: [Kaggle Learn <ExternalLink size={12} />](https://www.kaggle.com/learn) - Interactive micro-courses on Pandas, SQL, and ML.

## Cloud & DevOps (New)

- **[Roadmap.sh (DevOps) <ExternalLink size={12} />](https://roadmap.sh/devops)**: The definitive visual guide to DevOps skills.
- **A Cloud Guru**: Excellent for AWS/GCP certifications.
- **[Docker Curriculum <ExternalLink size={12} />](https://docker-curriculum.com/)**: A comprehensive tutorial on getting started with Docker.

## System Design (Advanced)

- **[Designing Data-Intensive Applications (Book) <ExternalLink size={12} />](https://dataintensive.net/)**: The "Bible" of distributed systems. Must read for Seniors.
- **[ByteByteGo <ExternalLink size={12} />](https://bytebytego.com/)**: Visual explanations of complex systems (YouTube channel is free).
- **[Grokking the System Design Interview <ExternalLink size={12} />](https://www.educative.io/courses/grokking-the-system-design-interview)**: Standard prep for FAANG interviews.

## Advanced Computer Science

- **[Teach Yourself Computer Science <ExternalLink size={12} />](https://teachyourselfcs.com/)**: If you don't have a CS degree, this is your curriculum.
- **[NAND to Tetris <ExternalLink size={12} />](https://www.nand2tetris.org/)**: Build a modern computer from first principles (logic gates -> OS).

## Tools & Productivity

- **[Oh My Zsh <ExternalLink size={12} />](https://ohmyz.sh/)**: Essential framework for managing your Zsh configuration.
- **[Tmux <ExternalLink size={12} />](https://github.com/tmux/tmux)**: Terminal multiplexer for power users.
- **[Vim Adventures <ExternalLink size={12} />](https://vim-adventures.com/)**: Learn VIM shortcuts while playing a game.
