### Command Line Mastery

**Resource**: [Linux Journey - Command Line Module](https://linuxjourney.com/)  

**Why This Resource**

## 2. Algorithmic Thinking

### Problem-Solving Fundamentals

**Resource**: [HackerRank: Problem Solving (Basic)](https://www.hackerrank.com/skills-directory/problem_solving_basic)  

**Why This Resource**  
These challenges force you to think algorithmically before writing code. You'll recognize patterns (loops, sorting, searching) that appear in every AI project.

**What You'll Learn**
- Loop patterns: Iterate through arrays, accumulate values, find patterns
- Conditional logic: Make decisions based on multiple criteria
- Array manipulation: Sort, filter, search, and transform data collections
- String operations: Parse and validate text (foundation for NLP)
- Basic algorithms: Linear search, simple sorting, frequency counting

**How to Use**
1. Start with "Easy" problems (aim for 10-15 problems)
2. **Critical approach**: Spend 10 minutes planning before coding
   - Write pseudocode in comments first
   - Identify the algorithm pattern (is it a loop? a search?)
3. After solving, review 2-3 other solutions to learn different approaches
4. Move to "Medium" problems once Easy feels comfortable (aim for 5-10 problems)
5. **Practice checkpoint**: Solve at least 20 problems total before moving on

**Problem-Solving Framework** (use this every time)
```
1. Understand: Restate the problem in your own words
2. Examples: Work through 2-3 examples by hand
3. Break down: What are the steps? What data structures?
4. Code: Implement your plan
5. Test: Try edge cases (empty input, single item, duplicates)
```

**Recommended Problem Types** (prioritize these)
- Array traversal and manipulation
- String parsing and validation
- Simple sorting and searching
- Counting frequencies (histograms)
- Two-pointer techniques

**Don't Skip This**  
It may seem unrelated to AI, but data preprocessing requires exactly these skills-loops through datasets, filtering invalid entries, transforming formats.

## Common Pitfalls & Tips

**Command Line**
- ⚠️ **Mistake**: Using `rm -rf` without double-checking the path (it's permanent!)
- ✅ **Fix**: Always use `ls` to confirm location before deleting
- 💡 **Tip**: Create aliases for common commands (e.g., `alias ll='ls -la'`)

**Algorithmic Thinking**
- ⚠️ **Mistake**: Starting to code immediately without planning
- ✅ **Fix**: Always write pseudocode in comments first
- 💡 **Tip**: If stuck for >20 minutes, read one solution's approach (not full code)

## Quick Reference

**Essential Commands Cheat Sheet**
```bash
# Navigation
cd directory_name    # Move into folder
cd ..                # Move up one level
pwd                  # Print current path
ls -la               # List all files with details

# File Operations
mkdir folder_name    # Create directory
touch file.py        # Create empty file
cp file1 file2       # Copy file
mv old new           # Rename or move
rm file              # Delete file (careful!)

# Text Search
grep "search" file   # Find text in file
grep -r "text" .     # Search in all files recursively
```

Save this for quick reference while working.
