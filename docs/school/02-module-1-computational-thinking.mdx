# 💻 Module 1: The Developer's Environment

![Placeholder: Banner Image for Developer Environment - Terminal and Logic Code](/img/terminal_hb.png)

## Goal
Get comfortable working in the terminal and a professional development environment.
This module introduces the tools and mental models used by engineers to interact directly with computers and servers.

## 1. Setup & Command Line

**Resources:**
- **[VS Code Setup Guide](https://code.visualstudio.com/docs/setup/setup-overview)**
- **[Linux Journey (Command Line)](https://linuxjourney.com/)**

**Why it matters:**

Modern software is built, deployed, and debugged in environments where graphical interfaces are limited or unavailable. Servers, cloud machines, and containers are controlled primarily through the command line.

The terminal allows precise, fast, and scriptable control over a system. Learning it is essential to working efficiently and independently as an engineer.

**What to expect:**

Learners will:
- Navigate the file system using terminal commands
- Create, move, rename, and delete files and directories
- Search and filter text using tools like grep
- Understand file permissions and execution rights
- Become comfortable working without relying on a mouse

By the end of this section, learners will be able to interact confidently with a computer using text-based commands.

## 2. Algorithmic Logic

**Resources:**
- **[HackerRank: Problem Solving (Basic)](https://www.hackerrank.com/skills-directory/problem_solving_basic)**

**Why it matters:**

Programming is not about syntax - it is about thinking in steps.

Algorithmic logic trains the ability to take a vague problem and break it down into clear, executable instructions. This way of thinking is foundational for coding, debugging, and designing systems.

**What to expect:**

Learners will:
- Practice breaking problems into smaller logical steps
- Use loops, conditionals, and arrays to solve problems
- Recognize common patterns in problem solving
- Build confidence translating ideas into structured logic

This section builds the mental habits required to think like a programmer before writing complex code.
