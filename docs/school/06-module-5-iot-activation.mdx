## 1. Teachable Machine & Rapid Prototyping

**Resources:**
- **[Google Teachable Machine](https://teachablemachine.withgoogle.com/)**

**Why it matters:**

Seeing AI work in real time builds intuition quickly. Teachable Machine removes setup friction and allows learners to focus on the core idea: collecting data, training a model, and observing predictions immediately.

It is a fast way to understand the full machine learning loop without deep technical overhead.

**What to expect:**

Learners will:
- Collect simple image or audio datasets
- Train a model in minutes
- Test predictions live using a webcam or microphone
- Observe how data quality affects model behavior

This section emphasizes experimentation and immediate feedback.

## 2. Edge AI & Simple IoT Deployment

**Resources:**
- **Raspberry Pi / Simple IoT Setup**

**Why it matters:**

Many AI systems run on edge devices rather than in the cloud. Cameras, robots, and sensors must make decisions locally, often with limited compute and power.

Understanding how models move from development to deployment is essential for building real-world AI systems.

**What to expect:**

Learners will:
- Deploy a trained model to a small device
- Connect AI models to cameras or sensors
- Run inference on real-world data
- Understand basic constraints of edge computing

By the end of this page, learners will see how AI systems transition from code to physical interaction.
