## <TerminalSquare /> 1. Setup & Command Line Interface

### <Cpu size={16} style={{ verticalAlign: 'text-bottom', marginRight: '0.35rem' }} /> Development Environment Setup

Your Integrated Development Environment (IDE) is your primary workspace for writing, debugging, and organizing code. Choose based on your experience level and needs:

- **Traditional IDEs** like VS Code offer versatility and extensive customization for experienced developers.
- **AI-Integrated IDEs** like Cursor or Antigravity provide intelligent code assistance, making them ideal for beginners or those working on complex projects.

:::note Why This Matters (Real Talk)
You might be tempted to skip the command line module and rely solely on your IDE's GUI. **Don't.** When your model breaks on a remote GPU server at 2 AM, the terminal is your only friend.
:::

**Your Mission:**

1. Choose and install a suitable IDE (VS Code, Cursor, Antigravity, or another).
2. Install **Required Extensions/Tools**: Python support, Jupyter integration, Git integration.
3. Install **Recommended**: Linting tools, error highlighting, and AI assistance features if available.

## <BrainCircuit /> 2. Algorithmic Thinking

### <ListChecks size={16} style={{ verticalAlign: 'text-bottom', marginRight: '0.35rem' }} /> Problem-Solving Fundamentals

<ResourceCard
  type="practice"
  title="HackerRank: Problem Solving (Basic)"
  url="https://www.hackerrank.com/skills-directory/problem_solving_basic"
  duration="4-6 hours"
  difficulty="beginner"
  why="Structured practice to build algorithmic thinking with immediate feedback and test cases."
/>

**Why This Resource**
These challenges force you to think algorithmically before writing code. You'll recognize patterns (loops, sorting, searching) that appear in every AI project.

**Suggested Workflow:**

1. **Understand**: Restate the problem.
2. **Plan**: Write pseudocode comments.
3. **Code**: Implement solution.
4. **Debug**: Test edge cases.

:::tip Pro Tip (From Experience)
If you get stuck for >20 minutes, read the discussion tab. Don't waste 3 hours spinning your wheels—learn the pattern and move on.
:::
