## ❓ How to Choose?

**Ask yourself:**

1. **"I love seeing my code interact with the physical world."** -> **Computer Vision**
2. **"I'm fascinated by how ChatGPT works and want to build my own."** -> **NLP**
3. **" I love finding patterns in chaos and predicting the future."** -> **Data Science**
4. **"I care about performance, scalability, and building robust systems."** -> **Software Engineering**

## 🚀 The Capstone

No matter which track you choose, you will finish Phase 3 with a **Capstone Project**.

- **Duration:** 4-6 weeks
- **Scope:** Solving a real-world problem from end-to-end
- **Standard:** Production-grade quality (deployed, documented, tested)

This capstone will be the "crown jewel" of your portfolio—the thing you talk about for 20 minutes in every interview.
