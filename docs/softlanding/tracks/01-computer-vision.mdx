# Computer Vision Track

### 👁️ Goal
**Focus**: Teaching machines to see.

### Curriculum
*   **[CS231n Winter 2016 by Andrej Karpathy](https://youtube.com/playlist?list=PLkt2uSq6rBVctENoVBg1TpCC7OQi31AlC&si=mzfqzQtahA33kMEO)** (Lectures #4 ~ #9)
    *   Deep dive into convolutional neural networks, covering architecture design, training techniques, and advanced topics like object detection and semantic segmentation that form the foundation of modern computer vision systems.
*   **[Deep Learning 1 (PyTorch) - University of Amsterdam](https://uvadlc-notebooks.readthedocs.io/en/latest/tutorial_notebooks/tutorial2/Introduction_to_PyTorch.html)** (Tutorials 3 through 6)
    *   Hands-on implementation of CNN architectures in PyTorch, building practical skills in image classification, data augmentation, and transfer learning for real-world vision tasks.
*   **[YOLOv1 Paper](https://arxiv.org/pdf/1506.02640)**
    *   Introduces real-time object detection as a single regression problem, teaching you how modern detection systems balance speed and accuracy for practical applications.
*   **[YOLOv2 Paper](https://arxiv.org/pdf/1612.08242)**
    *   Explores architectural improvements and training strategies that make object detection faster and more robust across different scales and object types.
