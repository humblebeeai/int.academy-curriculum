# Advanced AI & Coding



![Placeholder: Banner Image for Advanced AI - Neural Networks and Code](/img/advanced_ai.png)

## Goal

Master the tools and practices used by professional AI engineers to build, train, and deploy production-grade AI systems.

This module bridges theory and engineering practice, teaching you to implement deep learning models with PyTorch, understand modern LLM architectures, and write clean, maintainable code that scales beyond research prototypes.

## 1. Deep Learning & LLMs

*   **[CS231n Winter 2016](https://youtube.com/playlist?list=PLkt2uSq6rBVctENoVBg1TpCC7OQi31AlC&si=mzfqzQtahA33kMEO)** (Focus on Lectures #2, #3, #4)
    *   Provides rigorous foundations in neural networks and convolutional architectures from Andrej Karpathy, covering backpropagation mechanics, optimization techniques, and visual recognition systems that form the basis of modern deep learning.
*   **[A Deep Dive into LLMs](https://youtu.be/zjkBMFhNj_g?si=J0gM3k3mR8uX0kF_)**
    *   Explains how large language models work, breaking down transformer architecture and how these models process and generate text.
*   **[How I use LLMs](https://youtu.be/EWvNQjAaOHw?si=Pf1ndxkQFZjAZunP)**
    *   Demonstrates practical workflows for integrating LLMs into engineering practice, showing how to use AI tools effectively while maintaining code quality and understanding.

## 2. PyTorch Engineering

*   **[UvA Deep Learning Tutorials](https://uvadlc-notebooks.readthedocs.io/en/latest/tutorial_notebooks/tutorial2/Introduction_to_PyTorch.html)** (Chapter #2: Intro to PyTorch)
    *   Builds hands-on fluency with PyTorch tensors, automatic differentiation, and model building, teaching the practical skills needed to implement and train neural networks in the industry-standard framework.
## 3. Engineering Excellence

*   **Clean Code: A Handbook of Agile Software Craftsmanship** (Robert C. Martin) - **Read Until Chapter 10**
    *   Teaches principles of writing maintainable, readable code through naming conventions, function design, and code organization, transforming scripts into professional software that others can understand and extend.
*   **[LeetCode: Programming Skills Study Plan](https://leetcode.com/studyplan/programming-skills/)**
    *   Develops algorithmic problem-solving abilities through structured practice, building the mental fluency to translate ideas into efficient implementations and debug complex logic quickly.
    *   **Goal**: Turn abstract ideas into working code instantly.
