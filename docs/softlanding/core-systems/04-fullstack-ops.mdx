### 2.2 AI Model Integration

**Project**: Wrap Your AI Model in an API  
**Duration**: 4-6 hours

**Step-by-Step Implementation**

**Step 1: Create API Structure**
```python
from fastapi import FastAPI, File, UploadFile
from pydantic import BaseModel

app = FastAPI(title="My AI Model API")

class PredictionRequest(BaseModel):
    text: str  # or image_url, or other input type

class PredictionResponse(BaseModel):
    prediction: str
    confidence: float
```

**Step 2: Load Your Trained Model**
```python
import torch  # or tensorflow, or your framework
from your_model_file import YourModel

# Load model once at startup (not per request!)
model = YourModel.load("path/to/model.pth")
```

**Step 3: Create Prediction Endpoint**
```python
@app.post("/predict", response_model=PredictionResponse)
async def predict(request: PredictionRequest):
    # Preprocess input
    processed = preprocess(request.text)
    
    # Run inference
    prediction = model.predict(processed)
    
    # Return formatted response
    return PredictionResponse(
        prediction=prediction,
        confidence=0.95
    )
```

**Step 4: Test Your API**
- Run server: `uvicorn main:app --reload`
- Open auto-generated docs: `http://localhost:8000/docs`
- Test endpoints directly in Swagger UI
- Use `curl` or Postman for programmatic testing

**Requirements Checklist**
- [ ] Model loads once at startup (not per request)
- [ ] Input validation with Pydantic models
- [ ] Proper error handling (400 for invalid input, 500 for server errors)
- [ ] Reasonable response times (&lt;2 seconds for simple models)
- [ ] CORS enabled for your frontend domain
- [ ] API documentation at `/docs` is clear and accurate

### 2.3 Connect Frontend to Backend

**Project**: Full-Stack AI Application  
**Duration**: 3-4 hours

Update your webpage from Module 1 to call your FastAPI endpoint:

```javascript
async function getPrediction() {
    const userInput = document.getElementById('input').value;
    
    // Show loading state
    document.getElementById('loading').style.display = 'block';
    
    try {
        const response = await fetch('http://localhost:8000/predict', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ text: userInput })
        });
        
        const result = await response.json();
        
        // Display prediction
        document.getElementById('result').textContent = result.prediction;
    } catch (error) {
        console.error('Error:', error);
        alert('Prediction failed. Check console.');
    } finally {
        document.getElementById('loading').style.display = 'none';
    }
}
```

**Testing Your Full Stack**
1. Start FastAPI server: `uvicorn main:app --reload`
2. Open your HTML file in browser (or serve with `python -m http.server`)
3. Enter input → Click predict → See real AI prediction

**Common Issues & Fixes**
- **CORS error**: Add `app.add_middleware(CORSMiddleware, allow_origins=["*"])` to FastAPI
- **Connection refused**: Ensure FastAPI is running and URL matches
- **Slow predictions**: Move model loading outside the endpoint function

### 3.2 Containerize Your AI Application

**Project**: Dockerize Your FastAPI + Model  
**Duration**: 2-3 hours

**Step 1: Create Dockerfile**
```dockerfile
FROM python:3.10-slim

WORKDIR /app

# Install dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY . .

# Download model weights (or COPY if small)
RUN python download_model.py

# Expose port
EXPOSE 8000

# Run application
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**Step 2: Create requirements.txt**
```
fastapi==0.104.1
uvicorn[standard]==0.24.0
torch==2.1.0  # or tensorflow, etc.
# ... other dependencies
```

**Step 3: Build and Run**
```bash
# Build image
docker build -t my-ai-app .

# Run container
docker run -p 8000:8000 my-ai-app

# Test
curl http://localhost:8000/docs
```

**Requirements Checklist**
- [ ] Image builds without errors
- [ ] Container runs and serves API on port 8000
- [ ] Model loads successfully inside container
- [ ] Predictions work identically to local environment
- [ ] Image size is reasonable (&lt;2GB if possible)

**Optimization Tips**
- Use slim Python base images
- Install only production dependencies
- Use `.dockerignore` to exclude unnecessary files
- Consider multi-stage builds for smaller images

### 3.4 Deploy Your Containerized App

**Project**: Deploy to a Cloud Server  
**Duration**: 2-3 hours

**Deployment Options** (choose one):

**Option A: DigitalOcean Droplet** (Recommended for beginners)
1. Create Ubuntu droplet ($6/month tier)
2. SSH into server
3. Install Docker: `curl -fsSL https://get.docker.com | sh`
4. Copy your code: `scp -r myapp/ user@server-ip:~/`
5. Build and run: `docker build -t myapp . && docker run -d -p 80:8000 myapp`
6. Access your API: `http://your-server-ip/docs`

**Option B: Railway/Render** (Easier, but less control)
1. Push code to GitHub
2. Connect repository to Railway/Render
3. Platform auto-detects Dockerfile and deploys
4. Get a public URL automatically

**Option C: AWS EC2** (More complex, industry-standard)
1. Launch EC2 instance (t2.micro free tier)
2. Configure security groups (allow ports 22, 80)
3. SSH into instance
4. Follow same Docker deployment steps as Option A

**Verification Steps**
- [ ] API is accessible from any internet-connected device
- [ ] `/docs` endpoint shows Swagger UI
- [ ] Predictions work via `curl` from your local machine
- [ ] Server restarts don't lose your deployment (use Docker restart policies)
- [ ] Basic monitoring setup (check logs with `docker logs`)

## Common Pitfalls & Solutions

**Web Development**
- ⚠️ **CORS errors when frontend calls API**
  - ✅ Add CORS middleware in FastAPI with appropriate origins
  
- ⚠️ **JavaScript async/await confusion**
  - ✅ Always use `async` keyword with `await`, wrap in try-catch

**FastAPI**
- ⚠️ **Model loads on every request (slow predictions)**
  - ✅ Load model once at module level, not inside endpoint function
  
- ⚠️ **Large model files in repository**
  - ✅ Download weights at container build time, don't commit to Git

**Docker**
- ⚠️ **"Permission denied" errors in container**
  - ✅ Check file permissions, may need to run as non-root user
  
- ⚠️ **Image size is 5GB+**
  - ✅ Use multi-stage builds, slim base images, .dockerignore

**Deployment**
- ⚠️ **Can't connect to server**
  - ✅ Check security groups/firewall rules, ensure ports are open
  
- ⚠️ **Container stops after closing SSH session**
  - ✅ Run with `-d` flag (detached mode) or use `tmux`/`screen`
