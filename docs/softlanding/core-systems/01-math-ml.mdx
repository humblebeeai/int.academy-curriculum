## 3. Evaluation Metrics
How do you know if your model works?
*   **Metrics**: Accuracy, Precision, Recall, F1-Score, RMSE, MAPE, R-Squared.
*   **Confusion Matrix**: Learn to read it.
*   **Resource**: **[Google ML Crash Course: Classification](https://developers.google.com/machine-learning/crash-course/classification)**
