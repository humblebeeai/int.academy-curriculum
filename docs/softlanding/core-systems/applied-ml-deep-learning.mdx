## Applied ML and evaluation {#r2}

choose and assess models using evidence.

**Before you start:** Engineering Fundamentals data manipulation, statistics, and linear algebra; begin [Software Engineering for AI](/docs/softlanding/core-systems/software-engineering#r1) alongside this module.

### Learn

- Supervised regression and classification; linear/logistic models, trees, random forests, and SVM intuition.
- Preprocessing and a reproducible scikit-learn pipeline.
- Baselines, train/validation/test splits, cross-validation, and data leakage.
- Classification metrics: precision, recall, F1, confusion matrix, ROC-AUC, and precision–recall evaluation. Choose metrics based on the task.
- Regression metrics at an introductory level; overfitting, underfitting, and error analysis.

### Practice

- Choose a small public dataset or a built-in scikit-learn dataset; define the target and a task-appropriate metric.
- Create a baseline and compare at least two candidate models using the same split and preprocessing rules.
- Inspect mistakes and explain a useful improvement. Keep final test data out of model and preprocessing selection.
- Run a small regression example if your main project is classification, or a classification example if your main project is regression.

### Expected output

A reproducible modeling notebook or script, a results comparison, and a short error-analysis note. You can justify the split, baseline, metric, and model choice, and identify a leakage risk.

## Derivatives Preparation for Deep Learning {#derivatives-preparation}

### Before you start

Complete Math for AI and the applied ML section before this preparation. Derivatives are taught here; they are not required to enter Core Systems.

### Learn and practise

<ResourceCard
  showFullDescription
  title="Khan Academy differential calculus"
  url="https://www.khanacademy.org/math/differential-calculus"
  type="course"
  description="Required. Lessons on derivative intuition, the power rule, and the chain rule. Study slope as a local rate of change, partial-derivative intuition, gradients, and the update direction in gradient descent. Formal proofs and a complete calculus course are not required."
/>

### Practice

For a scalar squared-error function, compare a small finite-difference slope with the derivative at several points. Apply a few gradient-descent updates and plot the loss. Explain how an overly large step can increase loss. For a two-parameter example, explain why a gradient has one component per parameter. Revisit this example with PyTorch autograd in deep learning.

### Preparation evidence

Keep the derivative notebook, loss plot, and explanation of the learning-rate failure. Explain the update direction before beginning the deep learning training loop.

## Deep learning and pretrained models {#r3}

understand a training loop and use a pretrained model deliberately.

**Before you start:** [applied ML](/docs/softlanding/core-systems/applied-ml-deep-learning#r2), NumPy, matrix operations, and the [derivatives preparation](/docs/softlanding/core-systems/applied-ml-deep-learning#derivatives-preparation).

### Learn

- Weights, activations, losses, gradient descent, and forward/backward propagation.
- Tensors, shapes, broadcasting, autograd, nn.Module, and train/evaluation modes.
- Write a small training loop, diagnose training failures, and save/reload model weights.
- Distinguish training, pretrained inference, and fine-tuning. Develop an introductory transformer mental model.

### Practice

- Train a small neural network on a manageable dataset and plot training and validation behavior.
- Create one controlled training failure, such as an unsuitable learning rate or a shape mismatch, then diagnose and repair it.
- Save the weights, reload them in a separate inference script, and verify the output.
- Use a pretrained model for a task and explain the model's inputs, outputs, and limitations.

### Expected output

A small training implementation, a saved model, a separate inference example, and a debugging note. You can explain each part of the training loop and distinguish model learning from inference.
