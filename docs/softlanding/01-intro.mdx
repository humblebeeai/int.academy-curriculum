## 🌊 Why It's Called "Soft Landing"

The name comes from aerospace engineering. When a spacecraft lands on another planet, a "soft landing" means:

- **Controlled descent** – Not crashing, but not staying in orbit either
- **Gradual adjustment** – Adapting to new gravity, atmosphere, conditions  
- **Safe touchdown** – Ready to explore the new terrain

**That's exactly what this phase does for you.**

You've been in "orbit" – learning theory, following tutorials, building toy projects. Now you're **landing in the real world** of professional AI engineering:

- Real datasets (messy, incomplete, biased)
- Real constraints (time, compute, deployment)
- Real systems (networking, Docker, cloud infrastructure)
- Real expectations (code reviews, documentation, production quality)

The "soft" part? **We guide you through it with structure and support** so you don't crash and burn.

### Stage 1: Core Systems (Months 1-3)

**Goal:** Master the fundamental building blocks of AI engineering.

**What You'll Learn:**

**1. Math & ML Foundations**
- Linear algebra (how data transforms through layers)

- Neural network architectures (CNNs, RNNs, Transformers)
- PyTorch/TensorFlow proficiency
- Training loop implementation from scratch
- Understanding LLMs and modern AI systems

**3. Systems & Networking**
- Linux server administration
- Docker containerization
- API design (REST, GraphQL)
- TCP/IP, HTTP, networking fundamentals

**4. Fullstack Toolkit**
- FastAPI for model serving
- Database basics (SQL, NoSQL)
- CI/CD pipelines
- Cloud deployment (AWS, GCP, Azure)

**Time Investment:** 120-150 hours  
**Outcome:** You can build, train, and deploy ML models to production.

## 🚪 Entrance Requirements

### Option 1: Phase 1 Graduate (Recommended Path)

**You must demonstrate:**
- ✅ Completed all Phase 1 modules
- ✅ Submitted capstone project to GitHub
- ✅ Maintained learning journal for 8+ weeks
- ✅ Passed Phase 1 completion checklist

### Option 2: Direct Entry (Experienced Developers)

**You must demonstrate equivalent knowledge:**
- ✅ **Programming:** Fluent in Python, comfortable with Git/terminal
- ✅ **Mathematics:** Understand calculus derivatives, matrix multiplication, probability
- ✅ **Data Skills:** Can clean datasets with Pandas, create visualizations
- ✅ **Problem-Solving:** Solve LeetCode Medium problems

**Assessment:** Take the [Soft Landing Placement Test](#) and submit a data analysis project.

:::caution ⚠️ Don't Skip Phase 1 Unless You're Sure

**Common mistake:** "I know Python, I'll skip straight to AI."

**Reality check questions:**
1. Can you explain gradient descent mathematically (not just conceptually)?
2. Have you implemented backpropagation from scratch?
3. Can you debug CUDA out-of-memory errors?
4. Do you know when to use SVMs vs. neural networks?

If you answered "No" to any of these, **go through Phase 1 first**. It will save you weeks of frustration.

:::

## 🎯 What Success Looks Like

## 📝 Learning Approach: Project-Based

**Unlike Phase 1 (which was more tutorial-driven), Soft Landing is PROJECT-HEAVY.**

### Each Module Includes:

1. **Theory (20%)** – Lectures, readings, concept explanations
2. **Guided Practice (30%)** – Follow-along tutorials, small exercises
3. **Independent Projects (40%)** – Build systems from scratch
4. **Review & Iteration (10%)** – Code review, refactoring, documentation

### Example Project Arc:

**Week 1:** Learn PyTorch basics (tensors, autograd, nn.Module)  
**Week 2:** Implement a CNN from a research paper  
**Week 3:** Train it on a custom dataset  
**Week 4:** Deploy as a FastAPI service in Docker  
**Week 5:** Add monitoring, logging, error handling  
**Week 6:** Write documentation & present in Discord

**This is how real engineering teams work.** You're not just learning – you're practicing professional workflows.
