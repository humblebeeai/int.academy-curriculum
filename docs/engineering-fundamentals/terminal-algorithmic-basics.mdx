## Python Environment Setup {#environment-setup}

### Before you start

Run Python scripts and notebooks in an isolated environment. Complete terminal basics first; you should already be able to explain a short Python program.

### Learn and practise

<ResourceCard
  showFullDescription
  title="Python tutorial on virtual environments and packages"
  url="https://docs.python.org/3/tutorial/venv.html"
  type="tutorial"
  description="Required. Create and activate a virtual environment; install packages and record dependencies. Use the activation commands for your platform."
/>

<ResourceCard
  showFullDescription
  title="JupyterLab installation guide"
  url="https://jupyterlab.readthedocs.io/en/stable/getting_started/installation.html"
  type="documentation"
  description="Required. Install JupyterLab in your project environment and select the matching notebook kernel."
/>

Learn to check the Python version, create and activate a virtual environment, install packages, record dependencies, and select the same environment as a notebook kernel. Exclude the environment directory from Git. Core Systems later introduces uv project management.

### Practice

Create a project directory, then create a virtual environment:

```bash
python -m venv .venv
```

Activate it using the command for your platform in the Python tutorial. Use `python -m pip` to install NumPy, Pandas, and JupyterLab. Run a script that prints a small NumPy array, then run the same computation in a notebook. Record dependencies in `requirements.txt` and add `.venv/` to `.gitignore`.

Recreate the environment in a second practice directory from your dependency file. Intentionally select an interpreter without NumPy and explain the resulting import failure before correcting it.

### Assessment

The learner receives a small Python program containing:

- One runtime error
- One logic error
- One edge-case failure
- The learner must reproduce, explain, and fix all three problems.
- Logging, command-line debuggers, advanced breakpoints, and production observability are not required.

### Prerequisites
