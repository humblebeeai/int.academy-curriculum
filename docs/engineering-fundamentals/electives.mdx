## Advanced Statistical Inference {#advanced-statistical-inference}

### Before you start

Develop advanced inference after the required [Probability & Statistics](/docs/engineering-fundamentals/math-for-ai#probability-statistics) module.

Prerequisite: complete the probability and statistics section of Math for AI.

This elective covers Units 13–16 together. Complete all four units to finish the module.

### Unit 13 — Two-Sample Inference for the Difference Between Groups

Coverage:

- Comparing two population proportions
- Comparing two population means
- Confidence intervals for differences
- Two-sample significance tests
- Paired-data inference
- Interpreting group differences

### Unit 14 — Inference for Categorical Data

Coverage:

- Chi-square goodness-of-fit tests
- Chi-square tests for homogeneity
- Chi-square tests for independence
- Expected counts
- Test conditions
- Interpreting chi-square results

### Unit 15 — Advanced Regression

Coverage:

- Inference for regression slope
- Confidence intervals for slope
- Significance tests for relationships
- Residual analysis
- Transforming nonlinear relationships
- Interpreting regression evidence

### Unit 16 — Analysis of Variance

Coverage:

- Comparing more than two group means
- Between-group and within-group variability
- F-statistics
- ANOVA hypotheses
- Conditions for ANOVA
- Interpreting ANOVA results

### Complete this elective

To complete Advanced Statistical Inference, you must:

- Complete all four units: 13, 14, 15, and 16.
- Pass each corresponding unit test with at least 80%.
- Pass a separate elective verification assessment.
- Correctly select and interpret an appropriate inference method for a given problem.
