Python Environment Setup​

Before you start​

Run Python scripts and notebooks in an isolated environment. Complete terminal basics first; you should already be able to explain a short Python program.

Learn and practise​

tutorial

Python tutorial on virtual environments and packages

Required. Create and activate a virtual environment; install packages and record dependencies. Use the activation commands for your platform.

documentation

JupyterLab installation guide

Required. Install JupyterLab in your project environment and select the matching notebook kernel.

Learn to check the Python version, create and activate a virtual environment, install packages, record dependencies, and select the same environment as a notebook kernel. Exclude the environment directory from Git. Core Systems later introduces uv project management.

Practice​

Create a project directory, then create a virtual environment:

python -m venv .venv

Activate it using the command for your platform in the Python tutorial. Use python -m pip to install NumPy, Pandas, and JupyterLab. Run a script that prints a small NumPy array, then run the same computation in a notebook. Record dependencies in requirements.txt and add .venv/ to .gitignore.

Recreate the environment in a second practice directory from your dependency file. Intentionally select an interpreter without NumPy and explain the resulting import failure before correcting it.

Learn Git Branching

Required. Covering commits, branches, merging, and remotes.

  • Repositories

  • git status

Assessment​

The learner must:

  • Clone a repository.
  • Create a feature branch.
  • Make and inspect changes.
  • Create meaningful commits.
  • Push the branch to GitHub.
  • Open a pull request.
  • Resolve an intentionally created merge conflict.
  • Complete the merge.
  • Advanced rebasing, cherry-picking, Git internals, GitHub Actions, and release management are not required.

Prerequisites​

Complete terminal basics and environment setup.

Debugging Fundamentals​

Source estimate: 2–3 hours, provisional until piloted.

Goal​

Systematically locate, understand, and fix ordinary Python errors.

Learning resources​

Use selected sections from:

practice

LabEx — Code Debugging Techniques

Required. Tracebacks, print debugging, and the exercise

tutorial

VS Code Python debugging tutorial

Required. Breakpoints, stepping, and inspecting variables

Required topics​

  • Syntax errors
  • Runtime errors
  • Logic errors
  • Reading Python tracebacks
  • Reproducing a failure
  • Isolating the failing code
  • Inspecting values with print
  • Setting basic IDE breakpoints
  • Stepping through code
  • Inspecting variables
  • Verifying fixes with normal and edge-case inputs

Assessment​

The learner receives a small Python program containing:

  • One runtime error
  • One logic error
  • One edge-case failure
  • The learner must reproduce, explain, and fix all three problems.
  • Logging, command-line debuggers, advanced breakpoints, and production observability are not required.

Prerequisites​

Basic Python and a working local environment.
